Substitution

Substitution means replacing a variable with a known value.

Key idea

Once we know the value of a variable, we can work out the exact value of the expression.

Examples

  • If x = 3, then 2x + 4 = 10
  • If a = 5, then a² = 25

Quick rule

Put the value in brackets before calculating to avoid mistakes.

Practice

  • Evaluate 5x - 2 when x = 4.
  • Find 3a + 2b when a = 2 and b = 5.
  • Explain why substitution is useful in formulas.
