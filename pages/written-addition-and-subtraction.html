Written Addition and Subtraction

Written methods help us add and subtract bigger numbers carefully, using place value to keep our work neat and accurate.

Adding using columns

When adding numbers, line up the digits in the correct columns: ones, tens, hundreds, and so on. Start from the right-hand side and carry if the total is more than 9.

Example

  • 47 + 28 = 75
  • 134 + 65 = 199
  • 482 + 369 = 851

Quick rule

Always line up the digits by place value and work from right to left.

Subtracting using columns

Subtracting written numbers is similar. Line up the digits, start from the right, and borrow when needed. This keeps the place values correct.
