Algebra Basics

Algebra is a way of using symbols and letters to describe patterns, relationships, and unknown values. It helps us write general rules that work for many numbers at once.

What is algebra?

In algebra, letters such as x, y, and a stand for numbers we do not yet know. A variable can be used in expressions, equations, and formulas. For example, 3x + 2 means “three times a number, then add two.”

Key vocabulary

  • Variable: a letter that represents a number
  • Expression: a group of numbers, symbols, and variables
  • Equation: two expressions that are equal
  • Term: a part of an expression separated by + or -

Quick rule

Always do the same operation to both sides of an equation to keep it balanced.

Simplifying expressions

You can simplify expressions by combining like terms. Like terms have the same variable and the same power. For example, 3x + 2x = 5x, and 4y - y = 3y. This is because 3x and 2x both contain the same variable x.

Examples

  • 3x + 5x = 8x
  • 7a - 2a = 5a
  • x + 4 = 10
  • y = 3x + 2

Solving equations

To solve x + 7 = 12, subtract 7 from both sides. So x = 5.

Expanding and factorising

Expanding means removing brackets: 3(x + 4) = 3x + 12. Factorising is the reverse: 4x + 8 = 4(x + 2). These skills are very useful when solving equations and simplifying algebra.

Practice

  • Simplify: 5x + 3x
  • Solve: x + 7 = 12
  • Expand: 3(x + 4)
  • Factor: 4x + 8
  • Simplify: 6y - 2y + 3
