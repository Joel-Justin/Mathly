Adding and Subtracting Decimals

Decimals are numbers with a decimal point. To add or subtract them accurately, we line up the decimal points and work column by column.

Line up the decimal points

When adding or subtracting decimals, digits must line up in the correct place value. This makes sure tenths are added to tenths, hundredths to hundredths, and so on.

Examples

  • 2.5 + 1.25 = 3.75
  • 6.8 - 2.4 = 4.4
  • 4.32 + 2.7 = 7.02

Quick rule

Make the decimal points match, then add or subtract the digits in each column.

Important check

Always check that the number of decimal places is kept in the final answer. If needed, add zeros to make the columns line up perfectly.
