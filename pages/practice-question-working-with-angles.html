Practice Question: Working with Angles

This page brings together angle facts, triangle totals, and parallel-line relationships in one set of practice tasks.

Key idea

When solving angle questions, name the shape, note the angle fact, and then compute carefully.

Examples

  • If a straight line is split into two angles, they total 180°.
  • Angles in a triangle total 180°.
  • Parallel lines create equal corresponding angles.

Quick rule

Use the known angle fact before you calculate, and check if the answer fits the shape.

Practice

  • Solve one angle problem in a triangle.
  • Solve one angle problem using parallel lines.
  • Explain the reason behind each step.
