Vertical Percentage Calculations

Vertical percentage methods help organise calculations clearly and reduce mistakes.

Key idea

Writing a percentage question in a vertical layout helps show the relationship between the whole, percentage, and part.

Examples

  • Find the part when 20% of 75 is needed.
  • Find the total when 15% is 45.
  • Use a clear layout to compare one value to the whole.

Quick rule

Keep the percentage, amount, and whole lined up so the proportion stays clear.

Practice

  • Set up 25% of 80 in a vertical form.
  • Find 18% of 150.
  • Explain how a neat layout helps check the answer.
