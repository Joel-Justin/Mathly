Adding and Subtracting Fractions

To add or subtract fractions, the denominators need to match before the numerators are combined.

Key idea

We can only add like parts together, so fractions must be rewritten with a common denominator when needed.

Examples

  • 1/4 + 2/4 = 3/4
  • 1/2 + 1/4 = 3/4
  • 3/5 - 1/5 = 2/5

Quick rule

Find a common denominator, rewrite each fraction, then add or subtract the numerators.

Practice

  • Work out 5/8 - 1/4.
  • Explain why denominators must match.
